    Type Alias ValidationMetadata

    Execution metadata for one validation run (plan § 1, tasks 10-11). Answers "what actually ran", so a caller can tell a complete run from a partial one: a partial run is still valid when its selected checks passed, but omittedChecks is non-empty and the caller is expected to say so.

    Every field is optional so a validator that knows nothing about modes can still return a ValidationResult unchanged.

    OptionalschemaCompleted

    schemaCompleted?: boolean

    True only when every schema-eligible part was validated and no schema failed to load. False when schema validation never started, stopped early, or the engine could not compile a schema. Always false for a partial run, and for a DOCX/DOCM under word-valid, which judges the package by structural Word checks and compiles no schema. A PPTX walks its schemas under every profile, word-valid included (#340).
