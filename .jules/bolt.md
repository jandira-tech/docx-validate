## 2024-05-15 - Replace XPath Descendant Queries with Native DOM API
**Learning:** Using `xpath` package's `$$(".//w:del//w:t", dom)` triggers dynamic tree searches which cause severe performance bottlenecks for large documents in the `@xmldom/xmldom` package context.
**Action:** Use native DOM traversal APIs (`getElementsByTagNameNS`) over known namespaces, and reuse the parent's matched namespace URI to query inner child elements to deduplicate loops and significantly speed up large document traversals. Note: When replacing descendant XPath queries, since `getElementsByTagNameNS` iterates the subtree, inner elements can be matched multiple times. Using a `Set<Node>` replicates the unique node-set behavior of XPath seamlessly.
