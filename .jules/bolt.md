## 2024-05-18 - Fast DOM Traversal with @xmldom/xmldom
**Learning:** In the `@xmldom/xmldom` package, iterating through children using `node.lastChild` and `child.previousSibling` is relatively slow. Accessing the internal `childNodes` collection directly (and iterating it backwards with a standard `for` loop to match the `pop`-based stack traversal order) performs significantly faster.
**Action:** When implementing custom tree-walking algorithms over `@xmldom` trees, prefer `node.childNodes` array iteration over linked-list style `nextSibling`/`previousSibling` traversal for better performance. Also remember to destructure properties (e.g., `const { childNodes } = node;`) to pass strict linting rules.
